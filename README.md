# TwinFile 3.1.29 · C++ 原生版

**Windows 双栏文件管理器 · Android 工具箱 · 可选 AI / Agent · 原生插件扩展**

[下载安装包](https://github.com/350624/TwinFile/releases/latest) · [更新日志](CHANGELOG.md) · [安装说明](docs/INSTALL.md) · [使用手册与快捷键](docs/USAGE.md) · [源码构建](docs/BUILD.md) · [常见问题](docs/FAQ.md) · [问题反馈](https://github.com/350624/TwinFile/issues)

TwinFile 是面向 Windows 的双栏文件管理与 Android 工具箱。本版将桌面业务层、界面和设备协议迁为 **C++20 / Qt 6**，没有 Python 后端、解释器、PySide 或 Shiboken，也不会通过旧脚本补做功能。压缩依赖为原生 C；APK 编译、签名仍调用随包 Java 工具，Android 调试使用 ADB。

> 源码在本仓库，Windows 安装包在 [Releases](https://github.com/350624/TwinFile/releases/latest)。每版附更新日志、SHA256 与对应源码；Git 历史不存放安装器、个人配置或密钥。源码构建需要另行准备 [外部工具](tools/README.md)，普通安装用户无需自行配置构建环境。

## 运行和安装

- 面向 Windows x64。[下载 3.1.29 安装包](https://github.com/350624/TwinFile/releases/download/v3.1.29/TwinFile-3.1.29-Windows-x64-Setup.exe)或[独立直链下载器](https://github.com/350624/TwinFile/releases/download/v3.1.29/TwinFile-Downloader-3.1.29-Windows-x64-Setup.exe)，核对同页 `SHA256SUMS.txt` 后按向导安装。GitHub 的 Source code 不是安装器；也可按[构建说明](docs/BUILD.md)自行编译。
- 构建产物：便携版 `dist/TwinFile/TwinFile.exe`；独立下载器 `dist/TwinFileDownloader-3.1.29/TwinFileDownloader.exe`；安装器 `releases/TwinFile-3.1-Cpp-Setup.exe`（版本 3.1.29）。这些是构建后的路径，不是仓库已包含的文件。
- 完整发布包不需要安装 Python、Qt SDK 或编译器。手机需开启 USB 调试并授权电脑；HFX 需经用户确认安装配套手机端。源码编译与完整工具包的准备步骤不同，详见[安装说明](docs/INSTALL.md)。
- 新配置：`%APPDATA%/TwinFileNative/settings.json`。配置与旧版独立，菜单不再提供旧版设置/工作区导入入口。
- 第一次使用：点选左栏目录，再点选右栏目标目录，回到源栏选择文件，按 `F5` 复制到另一栏；顶部“助手”打开可选 AI，未配置 API 不影响文件管理。
- 启动时默认检查一次正式版更新，可在“更多 → 设置 → 软件更新”关闭；也可在此手动检查。只查询官方 GitHub 发布信息，不上传文件；新版本显示更新日志并打开发布页供手动下载，不会自动下载安装。
- 后续软件更新按[发布流程](docs/RELEASING.md)同步源码、更新日志和安装包；不含后台文件监控。

## 完整功能介绍

### 直链下载

点击“⋯ → 直链下载…”，粘贴 HTTP / HTTPS 文件链接，选择保存位置并开始。可设 **1–512 并发**，默认 16；显示进度、实时采样速度、大小、当前未完成请求数及恢复状态。服务器支持可靠分段且提供文件版本标识时并行下载，否则自动单连接。停滞分段主动重连，低速尾段可在连接上限内拆分剩余内容，最多重试两次；取消或关闭会中止连接并清理临时文件，不覆盖已有文件。高并发不保证更快，建议先用默认值。完整边界见[直链下载说明](docs/DOWNLOADS.md)。

也可单独安装 TwinFile Downloader，通过随附的 Chrome / Edge 扩展接管浏览器下载：首次在扩展管理页加载安装目录中的 `browser-bridge`，再按 `browser-bridge/README.md` 注册原生桥接。接管开关默认关闭，且不会继承浏览器 Cookie、登录状态或自定义请求头。安装步骤和限制见[浏览器接管说明](browser-extension/README.md)。

### MCP 服务

在“⋯ → 设置 → MCP 服务”启动后，支持 Streamable HTTP 的外部 AI 客户端可连接 TwinFile，使用自己的模型分析和修改授权目录中的文件、ZIP/APK、DEX/Smali，并按需读取手机文件。提供目录搜索、文本/二进制读写、校验、ZIP 创建更新提取、APK 信息/清单修改/测试签名及 DEX 解码回编。默认关闭、仅本机监听、强制 Bearer 认证；Home 读写、其它目录按规则授权，默认拒绝。详情及客户端配置见 [MCP 使用说明](docs/MCP.md)。

启动时会确认风险：持令牌客户端在可写目录直接操作，不逐项询问；覆盖/移动/永久删除要求当前 SHA256，不开放任意 shell 或安装。局域网选项使用明文 HTTP，仅用于可信网络。它是独立实现，不是 MT 插件或全部功能复制；未实测第三方 AI 客户端和真实手机，重要文件先备份。

### Dex 编辑器++

双击本地、APK/ZIP 内或手机上的 `.dex`，打开专用编辑器，不再交给文本编辑器。左侧按包名分组浏览类、筛选类名，右侧编辑 Smali，支持字段/方法跳转、当前类查找替换、撤销重做、Ctrl+S 编译保存及导出新 DEX。编译失败不覆盖原文件；保存会检查外部修改，包内/手机文件沿用校验回写流程。修改 APK 后仍需重新签名。

这是参考包/类导航工作流的独立实现，并非 MT 管理器插件或其私有引擎。支持标准 DEX 035–040；单文件 64 MiB、最多 50000 类、单类编辑 2 MiB，编译/解析可停止且有 180 秒时限。暂不提供 Java 反编译、跨 DEX 重构、引用交叉分析、ODEX/CompactDex/041 容器或 MT 全部功能。窗口为 C++/Qt，Smali 编解码复用已部署 Apktool 中的开放组件，附少量 Java 桥接源码，无 Python。

### 工作台界面

左侧“设备与磁盘”提供手机、各本地盘与 U 盘快捷入口，点击只切换当前活动栏。手机连接后直接进入共享存储，未授权/离线会提示原因；未连接时可点击“手机 · 未连接”重新检测。本地盘按实际盘符显示，可移动盘标记为 U 盘。磁盘在后台每 3 秒检测，手机每 5 秒检测；插拔更新入口，不强制跳转当前目录，重复结果不重建按钮。USB 硬盘若被 Windows 归类为固定盘，显示为普通磁盘；导航栏不枚举网络盘。

主界面采用统一工作台布局：顶部搜索与外观入口，左侧分组导航和可滚动收藏夹，中间是可调宽的双栏文件卡片。新建、复制、移动、删除、排序集中在文件区上方；“助手”按钮切换右侧 AI / 扩展，更多工具收进右上角“⋯”。原有快捷键保留。

两栏使用紧凑标签、图标导航、可编辑路径栏、名称/来源标题与 54px 文件行。活动栏用标签旁的小圆点标识，不再整圈高亮；文档、代码、PDF、音视频和文件夹使用统一图标，APK/EXE 与图片仍异步加载真实图标/预览。窄窗口可同时显示双栏与助手，收藏较多时只滚动导航列表，不撑高窗口；侧栏空白与文件区下方空白仍可取消选择。

文件图标统一为 36px 圆角方形底板，适配亮暗；APK/EXE 保持比例和留白，图片缩略图居中裁切填满，长截图不再挤成细线。拖拽预览使用相同遮罩；仅改变显示，不修改原图或原始缩略图缓存，高分屏按实际像素绘制并复用显示缓存。

### AI 侧栏与插件扩展

右侧提供可调宽、可收起的“AI / 扩展”侧栏，顶部“助手”按钮或 `Ctrl+Shift+A` 显示/隐藏，保留宽度和开关状态。AI 助手本身就是可停用的内置扩展；外部插件可以增加独立侧栏、设置页和命令，不必把每项功能写进主窗口。

侧栏采用 Codex 风格的简洁布局：无边框对话区、底部圆角输入框、圆形发送/停止键。附件从输入框内的“＋”添加，聊天/Agent 模式与模型名称同排显示；右上角提供新对话、接口设置和更多菜单，复制回答与隐私说明收进菜单。Agent 步骤可展开/收起，授权路径过长时省略显示、悬停查看完整路径。空白页不显示介绍，输入区随文字增高，六套主题均适配亮暗。

AI 服务由用户自行提供基础地址、模型 ID 和密钥，支持 OpenAI 兼容的 Chat Completions 接口及本机免密服务，不绑定服务商、不提供内置额度。支持流式文字、停止回答、复制回答、新对话；对话只在内存中保留，最多 20 轮/128K 字符。服务报错、限流、超时和不兼容响应均给出提示，不自动重试产生额外费用。修改接口、模型、密钥或系统提示词时清空旧会话，避免把旧记录发送给新服务。

接口设置提供“获取模型”：手动点击后异步请求同一服务的 `/models`，在可编辑下拉框选择；支持基础地址和完整聊天端点，不支持模型列表的服务仍可手填。获取不发送对话或文件，支持取消、超时和错误提示，修改地址/密钥后丢弃旧选项和请求。

普通聊天不自动上传文件上下文。“＋ 所选名称”仅附加当前已选文件的名称，“＋ 文本文件”仅读取手动选择的 UTF-8 文本（64 KiB 内）；两者均先预览，确认附加后也要点击发送才联网。每条消息最多一个附件；附件作为聊天历史在后续轮次继续携带，直到新建对话。回复按文字显示，不加载回答中的 HTML/本地图片。普通聊天不调用文件工具。

**内置 Agent**：输入框底部切换“Agent”，默认选择“修改前确认”并授权一个本机目录；工具结果会发送给当前 API。沿用你设置的模型/密钥，模型须支持标准 `tools/tool_calls` 和非流式 Chat Completions JSON，无须另装插件或 Python。默认可列目录、按名称搜索、查看信息、读取 UTF-8 文本、计算 SHA256；新建文件夹、文本和同目录文件重命名会弹出具体路径/内容，选择“允许这一次”才执行，不删除、不覆盖、不运行命令。

需要自动执行时，可在 Agent 权限下拉框显式开启“完全权限”。确认风险提示后，Agent 会以当前 Windows 账户权限通过受控 PowerShell 访问工作目录外文件、写入/覆盖/删除、运行程序及联网，不自动提权，也不逐项弹窗；命令有 8K 字符、120 秒、64 KiB 输出和进程组停止限制。完全权限不会由模型自行开启，只在当前对话有效，每次任务启动时固定本次权限；新对话、切换模式、修改接口或重启后恢复默认。完全权限的工作目录不会自动成为默认模式的授权目录。请仅对可信模型和明确任务使用。

可尝试：“找出名称包含 readme 的文件并总结其中的说明”“给 note.txt 算 SHA256”“新建一个整理计划.md，写入分类建议”。每次发送是**独立任务**，不携带普通聊天或上一任务的历史；仍可主动附加参考资料。界面保留本次运行的工具步骤，可停止任务；等待后台工具清理后才恢复可操作，不会撤销已完成的修改。最多 12 次工具调用、10 分钟总时限；不支持工具的模型会提示错误，可切回普通聊天，不自动重试消费额度。

授权只在当前面板生命周期有效，不落盘；聊天/Agent 默认聊天模式，切换模式会清空显示历史。修改接口、模型、密钥或系统提示词会同时撤销目录授权和完全权限。默认模式只支持本机普通目录，阻止绝对路径、`..`、网络路径、NTFS ADS、保留名称、符号链接/连接点和多重硬链接内容读取；完全权限由 Windows 用户权限决定，不是系统沙箱。工具上限及安全边界见 `PLUGIN_SDK.md`。请不要把 API Key、密码或隐私目录交给 Agent；停止不会撤销已完成修改。

密钥默认仅本次运行有效；选择记住后使用 Windows DPAPI 按账户加密到 `%APPDATA%/TwinFileNative/ai.json`，不写入普通 `settings.json` 或日志。远程端点要求 HTTPS，本机回环地址可 HTTP；不跟随重定向、不忽略证书错误。加密不能防御同账户恶意程序或已加载的可信插件。

“扩展”页支持本地 DLL 安装、显式信任、启用/停用、设置、注册命令与卸载。外部插件安装后保持停用，手动启用才执行；下次启动仅恢复已信任且 SHA256 未变的插件。不扫描并执行目录中的未知 DLL。SDK、完整示例源码和预编译“选择摘要”示例 DLL 随包提供，示例不会自动启用。

这是 **TwinFile 原生插件 API v1**，不是 VS Code 插件兼容层，没有线上扩展商店。原生 DLL 与主程序权限相同，不是沙箱，只安装可信来源的插件。接口、清单、编译环境和安全边界见 `PLUGIN_SDK.md`。

### 双栏与文件管理

左右栏独立浏览、选择、滚动和切换标签；每栏最多 32 标签。包含路径输入、前进/后退、上一级、驱动器、工作区恢复、收藏、隐藏文件和排序。刷新只作用于当前活动栏；列表、导航空白处及两栏各自底部 16 像素空白条均可取消选择。

每栏导航区带刷新按钮，目录读取期间显示旋转提示。刷新完成后列表轻微上移淡入（180ms）；进入文件夹从右侧轻滑淡入，返回上一级或退出文件夹则从左侧轻滑淡入（220ms），前进/后退按目录关系选择方向，包内浏览同样支持。动效不延迟后台读取，只重绘可见行，不复制整张列表、不为每帧重新加载缩略图；刷新保留选择和滚动位置。点击、键盘操作、滚动、调整列表大小或切换主题会结束当前过渡，避免影响命中与拖拽。设备轮询不反复播放动画。

“更多 → 外观 → 减少动画”会立即停止两栏的旋转、目录过渡和活动栏淡入，以及 MT 侧栏、最近/书签、菜单和新建窗口的过渡，下次启动继续保留该设置。MT 侧栏左右滑入/滑出，最近/书签面板上下展开/收起，遮罩随进度渐变；菜单淡入淡出，新建窗口轻移淡入/淡出。动画不延迟菜单动作或后台任务。

支持本地、手机和 ZIP/APK 内部的浏览、文件名搜索、新建、复制、移动、删除和重命名。批量重命名支持替换、前后缀、顺序编号、可编辑预览和冲突检查。本地删除用回收站；手机和包内删除须留意永久性。跨卷移动在复制发布成功后再删除源文件；默认不覆盖已有目标。

本地文件可多选拖到资源管理器、QQ 等接收标准 Windows 文件拖拽的程序，带文件图标和数量角标。拖出只提供复制，不会删除源文件；手机和包内文件先复制到本地。实际发送仍由接收程序确认。

### 图标与手机连接

保留用户所选 C 方案“流光玻璃”应用图标。图片、APK 和系统文件缩略图后台加载、缓存，只处理可见批次。`.APK`、`.apk.1`、`.apk.2` 等按 APK 识别，无需改 QQ 接收文件名；普通 `.1` 文件不误认成 APK。

图标使用独立的四线程工作池，完成一个就显示一个，不再等待整批。APK 优先原生读取清单和 `resources.arsc`，支持 Android 修改版 UTF-8、紧凑/稀疏资源表、WebP、矢量及自适应图标；彩色图标不叠加 `monochrome` 黑白主题层，缺少前景不会误显示为只有底色。常规解析失败才回退到 aapt2。EXE 等文件使用 Windows 自带图标。

两栏共用约 32MiB 内存缓存，并将成功解码的图标存入本地缓存，重新进入目录或重新启动无需逐个重解。缓存按路径、大小、修改时间失效；磁盘缓存周期性整理到 1024 张 / 64MiB 以内。读取失败会在本次目录中有限重试，不把空图标永久写入缓存。

启动自动检测手机，短暂重试并轮询连接变化，显示未授权和离线状态，不强制切换当前目录。手机传输通过直接连接 ADB 服务的原生 sync v1/v2，支持 64 位属性、流式 SEND/RECV 和目录连接复用，不是每个文件启动一个进程。

HFX 提供 USB + 用户选择的 WLAN 多轨传输，支持列目录、新建、推送、接收和删除。协议无加密/认证，只用于可信网络；不自动改防火墙或安装手机应用。

### 压缩、文本和图片

支持 ZIP/ZIP64、APK 浏览、创建、解压、包内增删改名、嵌套压缩包，以及手机/包内文本和图片回写。ZIP 重写经暂存和原子替换，检查外部修改并保留压缩方式、属性和时间。STORED 资源按 4 字节、未压缩 `.so` 按 16 KiB 对齐；修改 APK 后需要重新签名。

文本支持 UTF-8、UTF-16 LE/BE、GB18030、GBK、Big5、Windows-1252，保留 BOM 和换行，拒绝有损编码保存；支持字面/正则查找替换、语法高亮、未保存提示和原子保存。

图片支持动画、缩放平移、旋转翻转、调整尺寸、数值/框选裁剪、画笔、撤销重做、复制、原图保存和来源目录的上一张/下一张。解码和撤销有内存上限；不将动画静默覆盖为单帧。

### 比较与校验

文本比较使用有界 LCS 行对齐，带左右行号、增删颜色、替换行字符范围高亮、忽略空白和差异跳转。目录比较包含空目录和类型，可按大小、修改时间或 SHA256，支持筛选、进入子目录、双击两侧文本比较和导出。手机/包内比较经确认后暂存到电脑。

校验支持三来源流式 MD5 / SHA1 / SHA256；可粘贴预期值核对、导入 GNU/BSD 清单验证和导出清单。

### 媒体和歌词

播放器有本地及手机/包内按需播放列表、上一首/下一首、列表循环/单曲/随机、进度和音量。支持 FLAC/ID3 内嵌歌词与封面、本地 LRC/TXT、时间偏移、多时间戳和逐字歌词。手机/包内切歌按需暂存，关闭播放器清理。

在线歌词只在用户点击并确认关键词后请求 LRCLIB 或网易云，不自动上传歌曲信息、不写回歌曲文件。格式能否播放仍取决于解码器，不因列为媒体扩展名就保证可播。

### APK、Payload 与脚本

APK 工具包含反编译、工程副本修复、清单快速编辑、包名/版本/应用名修改、位图替换、保留自适应背景的前景替换或整体换图标、回编译、混淆组件原二进制清单恢复、对齐、独立调试签名和校验。构建不修改原 APK 或原工程。安装本地/包内 APK 需确认，调试签名不能覆盖原作者签名应用。

Payload 支持本地 BIN / OTA ZIP、远程 HTTP(S) Range、分区全选/取消全选与单项勾选、REPLACE/BZ2/XZ/ZSTD/ZERO/DISCARD，以及范围、文件一致性、操作和分区 SHA256 检查。远程下载连接数为 1–512，默认 16；本地分区并行数量为 1–8，默认 4。可自定义输出目录，使用程序默认 User-Agent，可选择是否明文记住直链。Payload 与直链下载均显式直连，不使用系统/应用/本地 HTTP 或 SOCKS 代理，不修改系统代理或 AI/API 设置。连续的小操作数据合并预读以减少请求，断连仅在有稳定版本标识时保留已接收数据并补读剩余部分；压缩 ZIP 先读取头部元数据列出分区，提取时才完整解压缓存并校验 ZIP CRC。解析、缓存、提取和校验显示内嵌进度；网络请求 15 秒空闲或单次超过 60 秒后中止，单段最多尝试八次；增量 OTA 明确拒绝。连接数是上限，服务器限流及线路决定实际速度；直连不绕过 VPN/TUN 路由。

可信 `.bat/.cmd` 经警告确认后可在新控制台运行，并附带 ADB/Fastboot 路径。

### 外观与明暗模式

顶部明暗图标或“⋯ → 外观 → 外观设置…”提供 TwinFile、MT 原版、miuix、Cream、bataUI01、macOS 六套风格；不再将 dark/light 作为独立主题。主题选择下方的亮色/暗色分段开关适用于每套风格，也可在外观菜单快速切换。切换立即生效并保存，保留七种强调色与减少动画；旧 dark/light 配置自动转换为 TwinFile 对应明暗模式，旧 MT/Cream/bataUI01 默认保持原来的亮色。MT 原版采用深灰路径顶栏、黑白图标、平直双栏、可收起的位置侧栏、底部导航、最近/书签面板和文件/文件夹共用新建窗口，保留桌面的路径编辑、多标签、顶部任务进度和助手。

miuix 使用独立布局：文件管理标题与当前路径、带滑动动效的左右活动栏切换、每栏文件夹标题与数量、金色文件夹图标、60 像素双行文件列表和带勾选标记的柔和选择背景。操作与含速度的任务进度放在双栏下方，路径输入和多标签仍在各栏；助手展开和窄窗口时自动收紧导航及搜索。浅色为灰白、深色为黑灰，菜单、弹窗和助手同步适配；减少动画立即结束分段滑动。切换其他主题恢复各自布局并保留路径与选择。这是原生 Qt 的 miuix 风格实现，不依赖 Android UI 库。

macOS 是在 Windows 上实现的 Finder 风格，不是原生 macOS：包含工作空间标题、灰色导航侧栏、渐变文件夹图标、紧凑文件行、分段标签、路径栏、按钮、菜单、滚动条、状态栏，以及 AI/插件面板和各工具弹窗的统一样式。保留 Windows 标题栏、拖动、最大化与系统窗口管理；没有伪称实现系统 Vibrancy 毛玻璃。原有目录/刷新动画继续生效，不增加持续后台重绘。内置文本编辑器的语法颜色也随明暗适配；第三方插件自绘或自行硬编码的样式由插件作者负责。

## 构建、测试、打包与导出

已验证工具链为 Windows x64、Qt 6.10.3 MinGW 64-bit、GCC 13.1、CMake ≥ 3.24。源码构建不要求 Python。新环境请先阅读[构建说明](docs/BUILD.md)，向 `build.ps1` 传入实际的 `-QtRoot`、`-CompilerRoot`，CMake 可通过 PATH 或 `-CMake` 指定。完整测试及打包需要另行准备[外部工具](tools/README.md)。

```powershell
.\build.ps1 -QtRoot 'C:\Qt\6.10.3\mingw_64' -CompilerRoot 'C:\Qt\Tools\mingw1310_64' -SkipTests
.\build.ps1 -QtRoot 'C:\Qt\6.10.3\mingw_64' -CompilerRoot 'C:\Qt\Tools\mingw1310_64' -ToolRoot 'C:\TwinFileTools' -Package
.\verify.ps1
.\verify-ui.ps1 -QtRoot 'C:\Qt\6.10.3\mingw_64'
.\package.ps1 -SkipBuild -Compiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
.\export-source.ps1 -Destination 'C:\Exports\TwinFile-source'
```

未指定 `-SkipTests` 时会运行四组 QtTest，结果在 `build/*-test-results.txt`。`-SkipTests` 只跳过测试执行，不表示测试通过；不准备外部工具时可先编译桌面程序，部分 Android 功能不可用。`-Package` 部署完整依赖、插件 SDK 与示例并拒绝 Python 产物。验证使用隔离设置、干净运行路径，不扫描真实手机；AI/Agent 测试仅调用本机模拟服务。安装脚本只编译安装器和 SHA256，不执行安装；源码导出默认不带外部工具、构建产物、配置或验证记录。

## 原生架构

- `src/core.*`、`operations.*`、`zip.*`：目录、搜索、安全操作、ZIP64 和嵌套回写。
- `src/adbsync.*`、`devices.*`、`hfx.*`：检测、ADB 同步、HFX 协议。
- `src/android.*`、`axml.cpp`、`apkproject.cpp`、`payload.*`：Android 资源、工程、签名、OTA。
- `src/model.*`、`pane.*`、`window.*`、`shell.*`、`thumbnails.*`：虚拟列表、双栏、拖拽、逐文件图标工作池/缓存、Windows 图标和脚本。
- `src/editor.*`、`difference.cpp`、`inspection.*`、`directory_dialog.cpp`：编码编辑、比较和校验。
- `src/media.*`、`media_tags.cpp`：播放、标签、歌词；`tests/`：隔离原生回归测试。
- `src/extensions.*`、`sdk/`：插件加载、信任索引、生命周期、扩展管理、公共接口和独立样例；`src/ai*`：内置 AI 扩展、异步聊天和 DPAPI 配置；`src/agent.*`：有界工具循环、授权目录和逐项确认，不改变公共 SDK ABI。
