# 安装与首次使用

[返回首页](../README.md) · [使用手册](USAGE.md) · [源码构建](BUILD.md)

## 1. 系统与下载

- 目标平台是 **Windows x64**；当前没有 Linux、macOS 或 Android 桌面端安装包。macOS 主题仅是 Windows 上的外观。
- 请从本项目 [Releases](https://github.com/350624/TwinFile/releases/latest) 取得安装包及 `SHA256SUMS.txt`。GitHub 的 “Source code (zip)” 不是免编译运行包。
- 完整运行包应含 Qt DLL、插件及所需工具，不要求用户安装 Python、Qt SDK 或编译器。媒体格式取决于发布包实际解码后端。
- 本地验证使用 Qt 6.10.3 / MinGW x64；不同 Windows 版本、驱动和安全软件仍需实际验证，不承诺所有旧系统可用。
- 重要文件先备份。建议以普通用户运行；不必为常规浏览授予管理员权限。

## 2. 安装版

1. 下载 `TwinFile-3.1.1-Windows-x64-Setup.exe` 及 `SHA256SUMS.txt`。
2. 核对来源和校验值，关闭正在运行的 TwinFile 后打开安装器。
3. 选择目录和是否创建桌面快捷方式，完成安装。项目使用独立的 `TwinFileCpp` 安装目录标识。
4. 从开始菜单或快捷方式启动。安装器不会默认勾选安装结束立即运行。

未签名或下载较少的安装器可能触发 Windows SmartScreen。请先核实仓库、文件哈希和来源，不要关闭系统安全防护来运行来源不明的副本。哈希只能检查文件一致性，不能代替签名或安全审计。

```powershell
Get-FileHash .\TwinFile-3.1.1-Windows-x64-Setup.exe -Algorithm SHA256
```

## 3. 便携版

1. 将完整便携压缩包解压到有写入权限的目录。
2. 保留 DLL、`platforms`、`imageformats`、`multimedia`、`tools` 等随包内容，运行 `TwinFile.exe`。
3. 不要只拷贝一个 EXE，也不要混用不同 Qt/编译器版本的 DLL。

“便携”指程序目录可整体移动，**不是配置完全保存在程序旁边**。常规配置位于当前 Windows 账户的 `%APPDATA%\TwinFileNative`。

## 4. 首次文件操作

1. 点击左栏后在侧栏选“下载”，或点路径栏输入目录。
2. 点击右栏，再选目标目录；侧栏始终切换当前活动栏。
3. 回到源栏选择文件，`F5` 复制、`F6` 移动、`F7` 新建目录。
4. `F2` 只刷新当前栏。点击空白处或按 `Esc` 取消选择。
5. 顶部明暗按钮快速切换；“⋯ → 外观”选择主题、强调色或减少动画。

## 5. 连接 Android 手机 / U 盘

- **U 盘**：插入后等待侧栏“设备与磁盘”更新，点击盘符进入当前栏。没有盘符、未就绪或被 Windows 归类为固定磁盘时，显示会有所不同。网络盘不在此自动枚举。
- **手机**：准备 ADB 工具，开启开发者选项及 USB 调试，用数据线连接并在手机允许本电脑调试；侧栏显示设备后点击进入共享存储 `/sdcard`。
- 未授权时先看手机确认框；离线时重新连接，检查数据线和驱动。无需手动安装 HFX 即可使用基础 ADB 文件功能。
- 磁盘后台约 3 秒、手机约 5 秒检测；启动也会检测。未连接手机入口可点击重试，不会自动跳转正在浏览的目录。
- HFX 是额外的 USB + WLAN 传输方式，需用户确认安装/启动手机端。明文、无认证协议只在可信设备和网络使用。

## 6. 可选 AI / Agent

1. 点击顶部“助手”或按 `Ctrl+Shift+A`。
2. 打开接口设置，填写 Chat Completions 基础地址、模型 ID 和 API Key；支持的服务可点“获取模型”。
3. 远程接口必须 HTTPS；回环地址本机服务可 HTTP。服务商决定费用、数据保留和可用模型。
4. 普通聊天不会自动读取目录。附件通过“＋”选择、预览后发送。
5. 需要文件工具时切换 Agent，再授权一个本机目录；默认修改前逐项确认。
6. 只有明确需要跨目录操作、命令或自动修改时，才手动开启“完全权限”并确认风险。此模式可删除/覆盖文件、运行程序和联网，不是沙箱，不自动提升为管理员。

默认不保存密钥。勾选记住后由 Windows DPAPI 按账户加密到 `ai.json`；聊天记录不写入磁盘。不要把密钥或私人内容填进问题反馈。

## 7. 更新、配置、卸载

- 更新前退出程序并备份 `%APPDATA%\TwinFileNative` 和重要文件，不要在文件传输过程中覆盖安装目录。
- 主配置为 `settings.json`；可选记住的 AI 配置为 `ai.json`。DPAPI 加密的密钥不可直接迁移给另一 Windows 账户。
- “⋯ → 导入旧版设置 / 工作区”可读取旧 JSON，不会修改旧文件；旧配置不应包含在公开仓库。
- 安装版通过 Windows“已安装的应用”卸载；便携版退出后移除程序目录。用户配置可能保留，若要清除请先备份并自行确认目录。
- 尚未完成所有系统上的真实安装/覆盖升级/卸载验收，详见[验证范围](../VERIFICATION.md)。
