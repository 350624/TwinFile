# 使用手册

[返回首页](../README.md) · [安装](INSTALL.md) · [常见问题](FAQ.md)

## 工作台与来源

外部 AI 连接：打开“⋯ → 设置 → MCP 服务”，设置 Home、权限和令牌后手动启动，客户端连接步骤及限制见 [MCP 服务](MCP.md)。不配置 MCP 不影响原有文件管理或内置助手。

左侧是常用目录、设备/磁盘和收藏，中间为左右独立文件栏，右侧为可收起的 AI / 扩展。点击任一文件栏会将其设为活动栏，侧栏导航、刷新、搜索及多数菜单操作针对该栏。活动栏标签旁有强调色小圆点。路径栏可直接输入本地目录，每栏最多 32 个标签，前进/后退历史各自独立。

设备侧栏按实际连接显示手机、本地盘符和可移动盘。点击手机进入共享存储；离线/未授权会提示。磁盘与手机后台轮询，不改变当前目录。收藏通过“⋯ → 收藏当前文件夹”添加；收藏多时侧栏可滚动。

可浏览三种主要来源：**本地文件、ADB 手机文件、ZIP/APK 内部**。不同来源的权限、删除方式及性能不同；并非所有本地功能都能直接对手机或包内执行。完整矩阵见 [MIGRATION.md](../MIGRATION.md)。

## 复制、移动、重命名与选择

1. 一栏选源文件，另一栏打开目标目录。
2. 顶部“复制”/`F5` 或“移动”/`F6` 将所选项送到另一栏。按钮的小箭头随当前栏切换：左栏操作时指向右，右栏操作时指向左；悬浮可查看来源与目标。窄窗口收起文字时仍保留方向箭头。
3. 也可在文件列表使用 `Ctrl+C` / `Ctrl+X` / `Ctrl+V`；输入框获得焦点时仍是普通文本快捷键。
4. 用 `Ctrl`、`Shift` 组合选择多项；顶部“全选”和“取消全选”只处理当前栏，不改变另一栏的选择。全选范围是当前列表（搜索时仅搜索结果）；点列表空白、侧栏空白、文件栏底部空白条或 `Esc` 也可取消选择。
5. 文件右键菜单提供与来源匹配的操作；重命名也可通过菜单打开。**F2 是刷新，不是重命名。**
6. `Ctrl+M` 打开批量改名，设置替换、前后缀或编号，编辑预览并处理冲突后确认；仅对支持的本地普通项使用。

默认不覆盖已有目标。本地删除使用回收站；手机和包内删除可能永久生效。跨卷移动先成功发布目标再删除源文件，但跨手机/包内操作不是完整事务，停止也不会自动撤销已完成部分。

文件操作、下载和 Payload 共用顶部工具栏中的任务区域，显示阶段、进度和处理速度，点击取消图标停止任务；运行时仍可浏览目录。同一时刻只运行一个任务，未知总量时显示不确定进度，准备/校验等未报告字节的阶段显示 0 B/s。完成或错误留在栏内，悬浮可查看完整信息。助手展开或窗口较窄时工具按钮显示图标。

本地文件支持多选拖到资源管理器、QQ 等接受 Windows 文件拖拽的应用，有图标和数量预览，按复制方式拖出；**不支持手机/包内直接拖出，也不支持从外部拖入本软件**。先把手机/包内文件复制到本地。目标软件决定是否接受及最终如何发送。

## 浏览、刷新、图标和搜索

- 双击目录进入；导航按钮返回、前进、上一级；`Ctrl+L` 聚焦路径。
- 刷新只处理活动栏。目录/刷新过渡不阻塞后台读取，刷新保留可恢复的选择和滚动；“减少动画”可关闭。
- “排序”选择名称、大小、时间等；“⋯”切换隐藏文件。`Ctrl+F` 按名称搜索当前来源，**不是系统全盘内容索引**。
- APK 名称大小写不敏感，`.apk.1`、`.apk.2` 也识别为 APK；普通 `.1` 不会误判。
- 图片、APK/EXE 图标异步显示并缓存；圆角底板统一留白，图片中心裁切仅影响缩略显示，不修改原图。无图标或解析失败时保留类型图标。

## 压缩包、编辑与属性

- ZIP/ZIP64/APK 支持浏览、创建、解压和包内增删改名；嵌套包及手机/包内文本图片编辑通过临时副本回写。
- 修改前核对原文件，保存时会检测部分外部更改；不要让多个程序同时编辑同一个包。APK 内容修改后须重新签名。
- `Space` 或右键“属性（空格）”查看所选项的名称、位置、修改时间、逻辑大小及精确字节数。文件夹后台累计子文件大小（包含隐藏项），同时显示文件与子文件夹数量；包内按未压缩大小统计，不解压文件。链接不跟随，多选父子项目不会重复计数；读取失败显示“未完成”，关闭属性窗口会取消统计。没有选择时查看当前目录。
- 双击文本进入编辑器，支持 UTF-8/UTF-16、GB18030/GBK、Big5、Windows-1252、查找替换、正则、高亮、编码/BOM/换行保留。`Ctrl+S` 保存，有损编码不会静默保存。
- 文件夹右键保留压缩，隐藏 ZIP/APK 解压与 APK 工具；解压出现在单个本地压缩包或包内文件的菜单，APK 工具只出现在单个本地 APK 的菜单。
- 图片查看/编辑支持缩放平移、动画、旋转翻转、尺寸、裁剪、画笔、撤销重做、复制及上一张/下一张；内存有上限，不会将动画静默覆盖为单帧。

## 比较、校验、媒体

通过“⋯”选择文本比较、目录比较或校验。文本比较支持行对齐、替换字符高亮、忽略空白及差异跳转。目录比较可按大小、时间或 SHA256，显示空目录/类型冲突，支持筛选与导出；手机/包内可能先经确认暂存。

校验支持 MD5 / SHA1 / SHA256，粘贴预期值核对，导入/导出 GNU/BSD 清单。**哈希一致只证明字节一致，不证明文件安全。**

媒体播放器支持列表、循环/单曲/随机、进度音量、内嵌及本地 LRC/TXT 歌词与封面；手机/包内媒体按需暂存。在线歌词需用户点击并确认关键词才查询，不自动上传媒体信息。播放支持取决于实际 Qt/FFmpeg 后端。

## Android / APK / Payload / HFX

### Dex 编辑器++

双击 `.dex`（也支持 APK/ZIP 内或手机上的 DEX），等待左侧包/类列表加载，选择类编辑右侧 Smali。类名筛选在左上；右侧字段/方法下拉跳转，查找与替换只作用于当前类。切换类会把修改暂存在临时工作区，**不等于已写回 DEX**；按 `Ctrl+S` 或“编译保存”，确认后才编译并替换原文件。“导出 DEX”编译到一个不存在的新路径，不覆盖已有文件，也不算保存原件。关闭尚未编译的修改会询问。

编译错误显示在底部，原文件保持不变；可继续修正或导出。原 DEX/包内条目已被其它程序更改时拒绝覆盖，建议重新打开。手机和嵌套容器回写沿用现有流程，失败时查看错误提示。APK 内容改变后原签名失效，需回到 APK 工具重新签名后安装。请先备份，仅编辑你有权修改的程序。

目前支持 DEX 035–040，单个 DEX ≤64 MiB、类数 ≤50000，单类编辑 ≤2 MiB；Smali 输出总量有上限，外部进程 ≤768 MiB Java 堆、180 秒超时，可点击“停止”。不支持 CompactDex/ODEX/041 容器、Java 反编译、跨 DEX 搜索/合并和 MT 全部高级功能。工具完全在本机运行，不上传 DEX。

这些工具从“⋯”或对应 APK 的菜单进入；需要外部程序时会使用[工具依赖](../tools/README.md)。

- **APK 工程**：本地 APK 右键进入反编译；进入包含 `apktool.yml` 的工程目录后，从“⋯ → APK 工程”使用工程编辑、回编译和签名。支持工程副本修复、清单编辑、包名/版本/名称修改、位图及自适应图标替换、对齐与校验。不原地修改原 APK/原工程。调试签名不能覆盖原作者签名应用；安装到手机要确认，不自动刷机。
- **Payload**：选择本地 BIN/OTA ZIP 或远程 HTTP(S) 直链。远程直链窗口直接选择“保存位置”和下载线程数量（1–512，新设置默认 16），记住上次目录与线程；读取分区列表后勾选分区，可再次调整目录和下载线程。远程连接总量由全部分区共用，按每段约 256 KiB 自动减少小文件连接，单个大分区和压缩 OTA 缓存均支持多连接。使用程序默认 UA，可选择是否明文记住直链。本地分区并行数量独立为 1–8。压缩 ZIP 只解压头部元数据来列分区，提取时仍需完整下载解压缓存及 CRC 校验；主界面顶部任务栏显示阶段、进度与处理速度，支持取消，不弹进度或完成窗口。网络空闲 15 秒或单次请求超过 60 秒后中止，最多尝试三次；远端须正确支持 Range/206。校验文件一致性和操作/分区 SHA256。支持完整 OTA 的 REPLACE/BZ2/XZ/ZSTD/ZERO/DISCARD，**拒绝增量 OTA**。
- **HFX**：选可信手机及 WLAN 通道，经确认安装/启动配套手机端，再选择传输操作。协议无加密/认证，不用于公共网络，不自动开防火墙。
- **脚本**：可信 `.bat/.cmd` 可经警告确认在新控制台执行并带 ADB/Fastboot 路径。不要运行陌生脚本。

## AI 与 Agent

接口设置填写兼容 Chat Completions 的地址、模型及 Key；“获取模型”只请求 `/models`，失败可手填。远程只允许 HTTPS，本机回环地址可 HTTP；不绕过证书验证、不跟随重定向。费用/隐私由你选的服务决定。

**聊天**仅发送输入和主动附加内容，不自动扫描目录。“＋”添加所选名称或手选 UTF-8 文本（64 KiB 内），先预览再发送。对话仅保存在内存，最多 20 轮；更改服务配置会清空旧会话。

**Agent**要求模型支持非流式标准 `tools/tool_calls`。每次发送是独立任务：

| 权限 | 可做什么 | 用户控制 |
| --- | --- | --- |
| 修改前确认（默认） | 授权目录内列目录、搜索名称、文本读取、信息与哈希；新建目录/白名单文本、同目录文件重命名 | 先选本机普通目录；修改逐项确认；不允许删除、覆盖或 shell |
| 完全权限 | 通过 PowerShell 跨目录读写、覆盖、删除、运行程序、联网，受当前 Windows 账户权限约束 | 用户显式确认开启；不自动提权；当前对话有效；模型不能自行开启 |

任务最多 12 次工具调用/10 分钟；命令最多 120 秒，输出受限。可展开工具步骤或点停止；停止不能回滚已经完成的操作。新对话、切换模式、变更 API 或重启重置完全权限。默认目录限制不是系统沙箱；完全权限及原生插件具有真实副作用，慎用于敏感文件。

普通聊天示例：“帮我解释这段配置。” Agent 示例：“列出授权目录中的 markdown 文件”“计算 note.txt 的 SHA256”“新建一个整理计划.md，写入分类建议”。工具返回的文件内容是不可信参考，不能充当用户授权。

## 插件与外观

“扩展”页安装本地 DLL 后默认停用；核对作者和 SHA256，显式信任并启用后才加载，可设置、停用、卸载。内置 AI 也可停用。原生 API v1 **不是 VS Code 兼容层**，没有线上商店或进程沙箱。第三方 DLL 与主程序同权限，仅安装可信插件。开发流程见 [PLUGIN_SDK.md](../PLUGIN_SDK.md)。

## 软件更新

默认在每次启动后异步查询一次 TwinFile 官方 GitHub 最新正式版；可在“更多 → 设置 → 软件更新”关闭启动检查，或点击“检查更新”。查询仅发送固定版本检查请求，不包含文件、路径或 AI 密钥。发现更新时显示版本和更新日志；“前往下载”打开官方发布页，由用户自行下载、关闭软件并运行安装包。不会静默下载、安装或替换文件。离线、GitHub 限流或没有正式版本时，手动检查会显示原因；启动检查失败不会弹出错误打断使用。

TwinFile、MT 原版、Cream、bataUI01、macOS 五套主题各支持亮/暗，另有七种强调色和减少动画。macOS 只是 Finder 风格，保留 Windows 原生标题栏，不具备 macOS 系统毛玻璃。

“MT 原版”沿用旧 MT 主题设置，采用深灰路径顶栏、黑白类型图标和无圆角双栏；顶部路径与数量跟随活动栏。顶部路径可直接输入地址，回车跳转，Esc 取消；Ctrl+L 聚焦地址。MT 模式隐藏每栏重复的标签/导航地址区，多标签仍可通过 Ctrl+T、Ctrl+W、Ctrl+Tab 和 Ctrl+Shift+Tab 管理，切换其他主题后恢复显示。左上菜单图标覆盖展开位置/设备侧栏，不挤压双栏，选择位置后收起；右上竖向菜单提供刷新、搜索、选择、排序、隐藏文件、书签与设置，更多工具仍可访问下载、Payload 和 APK 等功能。从底栏向上拖动/触摸上划打开全宽“最近 / 书签”面板，也可在底栏向上滚动或用菜单打开；单击目录进入，向下拖动标签栏/底部箭头、点击箭头/遮罩或按 Esc 收起。底栏普通点击仍执行原导航功能；最近目录保留本次运行最多 40 项，本地书签沿用持久化收藏。

MT 侧栏滑入/滑出，最近/书签从底部展开并向下收起，两者的遮罩同步渐变；侧栏动画途中再次点击菜单按钮可反向展开，Esc 也可收起侧栏。菜单使用淡入淡出，新建窗口使用轻移和淡入淡出并带背景遮罩。减少动画会立即完成当前过渡并关闭之后的动效；切换主题、活动栏或调整窗口时清理不再适用的覆盖面板，避免残留遮罩。

底部五个图标依次为后退、前进、新建、交换左右窗口、上一级；交换移动完整文件栏并保留其标签、历史和选择。新建窗口输入名称后选择“文件”或“文件夹”，无效名称不会创建。顶部复制/移动方向箭头、全选/取消全选、任务进度与速度、助手照常可用。其他主题仍可在每栏输入路径，窗口继续使用 Windows 标题栏。
