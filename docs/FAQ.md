# 常见问题

[返回首页](../README.md) · [安装](INSTALL.md) · [使用手册](USAGE.md)

### 下载了源码为什么没有 EXE？
源码归档不是运行包。请查 [Releases](https://github.com/350624/TwinFile/releases) 是否有正式成品，或按[构建说明](BUILD.md)编译。当前仓库不包含本地构建目录和历史安装包。

### 提示缺少 Qt DLL / Windows 平台插件？
不要单独移动 EXE；重新解压整个可信运行包。开发环境需 Qt/MinGW 的 `bin` 在 PATH，独立包需运行 `windeployqt`；勿混装不同 Qt/架构 DLL。安全软件隔离文件时先核查来源，不要盲目禁用防护。

### 手机未出现或显示未授权？
确认是数据线、USB 调试已开、手机已允许本电脑，检查 Windows 驱动和 ADB 工具。等待轮询或点击“手机 · 未连接”重试；离线可重新连接。基础功能不要求安装 HFX，也不自动获得 root 或全部 Android 目录访问权。

### 为什么 U 盘当作本地磁盘显示？
入口类型由 Windows 报告的驱动器类型决定，USB 硬盘常被归类为固定盘。不具盘符、未就绪或网络盘不会作为正常可移动盘入口显示。

### APK 没图标，或者 `.apk.1` 是否支持？
支持 `.APK`、`.apk.1` 等 QQ 常见后缀；普通 `.1` 不等于 APK。图标后台加载并缓存，复杂/损坏或不支持的资源会保留通用图标；不能保证每个第三方 APK 都能解析。缩略图圆角/裁切不修改原文件。

### F2 为什么不是重命名？
本软件沿用 F2 刷新活动栏；重命名走文件菜单，批量改名为 `Ctrl+M`。完整快捷键见[手册](USAGE.md#快捷键)。

### 拖到 QQ 没反应？
只支持本地文件按 Windows 标准拖出，先把手机/包内文件复制到本地。目标程序须接受文件拖拽，不同进程权限级别也可能影响拖放；QQ 收件仍需真实环境验证。本软件不替目标应用自动发送。

### APK 修改后不能覆盖安装？
Android 要求升级签名兼容。TwinFile 的本地调试签名不是原作者签名；不要删除重要应用/数据来绕过错误。先备份并确认自己有权修改、安装该 APK。

### 远程 Payload 无法提取？
链接须指向真实文件，支持正确 Range/206，并在任务期间保持一致。登录页、过期签名 URL、下载中转或增量 OTA 不适用。3.1.8 起压缩 ZIP 先读取元数据列分区，提取时才完整缓存；进度窗口显示当前阶段。网络空闲 15 秒或单次请求超过 60 秒会中止，最多尝试三次，取消可停止等待。线程数量控制同时提取的分区数（1–8），不会加速单个 ZIP 压缩流的解压。使用默认 UA；直链可能含隐私，记住直链会明文落盘，不要上传到 Issues。

### “获取模型”失败，但聊天接口可用？
有些服务不提供 `/models`，可手填其实际模型 ID。检查基础 URL、Key、HTTPS 与错误提示；不支持 Azure 专有参数/认证形式。Agent 另外需要标准非流式 `tools/tool_calls`，只会文字聊天的模型不能执行工具。

### 完全权限等于管理员权限吗？
不是。它取消 Agent 的授权目录/逐项确认限制，以当前 Windows 用户执行命令和文件操作；不自动 UAC 提权，也不是系统沙箱。若主程序本来以管理员运行，其命令也会继承相应风险。只有用户显式开启，默认关闭；停止不能撤销已完成操作。

### 能安装 VS Code 插件吗？
不能。这里是 TwinFile 原生 Qt/C++ 插件 API v1，编译工具链需匹配。DLL 与主程序权限相同，不应安装来源不明的插件。

### 如何报告问题？
在 [Issues](https://github.com/350624/TwinFile/issues) 提供版本、Windows/架构、来源类型（本地/手机/包内）、复现步骤、预期与实际结果。截图打码路径、账号、设备序列号；不要上传密钥、签名文件或完整私人日志。安装、设备、真实服务商验证的范围见 [VERIFICATION.md](../VERIFICATION.md)。
