# 直链下载

[返回首页](../README.md)

独立下载器及浏览器接管见 [browser-extension/README.md](../browser-extension/README.md)。

## 使用

1. 运行 3.1.14 或更新的 `dist/TwinFile/TwinFile.exe`、独立 `dist/TwinFileDownloader-3.1.14/TwinFileDownloader.exe`（或对应安装版）。正在运行的旧进程不会自动变成新版本，需正常退出后重新打开。
2. TwinFile 主程序中点击顶栏“⋯ → 直链下载…”；独立下载器直接打开即进入下载窗口，也可由浏览器扩展传入链接。
3. 粘贴 HTTP / HTTPS 文件直链，点“选择位置…”指定本机已存在目录中的新文件名；主程序记住上次下载目录，首次默认本地活动栏目录或系统“下载”目录。独立下载器默认使用系统“下载”目录。
4. 选择连接数（默认 16，范围 1–512），点“开始下载”。主程序收起设置窗口，在复制/移动/删除右侧的顶部任务栏显示阶段、进度、下载量/总量及速度，可点击取消图标。独立下载器在自身窗口内显示进度和当前请求数。停传后速度降为零；大小未知时显示不确定进度。
5. 主程序完成或失败后留在任务栏显示结果，不弹进度或完成窗口；可重新打开下载设置查看完整详情、打开目录。取消立即中止连接并删除临时文件；独立下载器下载中关闭需确认。

## 一致性与回退

- 用一字节 Range 请求检测。200 响应直接使用单连接；服务器拒绝 Range 的常见响应也重新发起普通 GET。
- 只有有效 Content-Range、强 ETag 或 Last-Modified、足够大小才分段。每段至少约 256 KiB，512 并发需文件至少约 128 MiB；小文件自动减少实际连接数。服务器/代理/系统可能进一步限制或拒绝并发。
- 分段请求使用 If-Range；校验 206、精确起止/总大小、版本标识和 identity 编码，避免误拼版本已变化或忽略 Range 的响应。版本变化/不正确响应停止，不发布损坏成品。
- 429、5xx 或可恢复的分段连接中断最多重试两次（1/2 秒延迟），仅请求该段尚未写入的部分。不持久保存断点；单连接失败需重新开始。
- 每秒检查分段：已收到数据后连续 15 秒无数据，或等待首次响应超过 30 秒，主动重连。下载超过 90% 时，分段连续 30 秒新增不足 32 KiB 也触发恢复；连接有余量且数据足够时，将其未下载部分拆成最多四段，每段至少约 256 KiB，总未完成请求不超过用户连接上限。子段继承重试次数，耗尽会明确失败，不无限等待或循环。
- 同一目录的随机 `.twinfile-download-*.part` 临时文件，完成后检查长度、刷新磁盘并改名；不覆盖已有目标，下载途中出现同名文件也失败并保留原文件。磁盘已知空间不足时拒绝；写入失败会停止。文件大小/范围/版本检查不是来源真实性或密码学完整性验证，重要文件请再比对官方 SHA256。
- 探测传输超时 20 秒、下载传输超时 60 秒、整任务最长 24 小时；上限 1 TiB。正常失败/取消/关闭清理临时文件，强制结束进程或断电可能残留，可手动删除。

## 限制

不支持登录页、Cookie/自定义认证、内嵌账号密码链接、URL 片段、磁力/BT、跨重启断点、暂停、批量队列或自动解压/安装。带查询参数的临时签名直链可使用，但过期可能失败。遵守服务器限流和使用条款；高连接数不保证更快，遇限流请降低并发。跟随最多五次不降级重定向，不绕过 TLS 证书验证。主程序仅持久保存下载目录，不保存下载链接或完整文件名；无遥测。下载会直接访问用户填写的服务器。主程序共用一个任务槽，下载、文件操作与 Payload 不同时启动。

自动回归仅访问本机模拟 HTTP 服务，包括实开 512 连接、内容 SHA256 对比、回退/异常/重试/取消与 UI 主题，不替代公网/CDN/代理/断电/超大文件性能测试。没有自动下载用户先前提供的固件。
