# 直链下载

[返回首页](../README.md)

## 使用

1. 运行 3.1.5 或更新的 `dist/TwinFile/TwinFile.exe`（或对应安装版）。正在运行的旧进程不会自动变成新版本，需正常退出后重新打开。
2. 点击顶栏“⋯ → 直链下载…”。同一主窗口复用一个下载窗口，不阻塞双栏浏览。
3. 粘贴 HTTP / HTTPS 文件直链，点“选择…”指定本机已存在目录中的新文件名；本地活动栏目录作为默认浏览位置。
4. 选择连接数（默认 16，范围 1–512），点“开始下载”。显示下载量/总量、平均速度和实际并发；大小未知时显示不确定进度。
5. 完成后点“打开目录”。取消立即中止连接并删除临时文件；下载中关闭需确认，退出主程序也会先询问。

## 一致性与回退

- 用一字节 Range 请求检测。200 响应直接使用单连接；服务器拒绝 Range 的常见响应也重新发起普通 GET。
- 只有有效 Content-Range、强 ETag 或 Last-Modified、足够大小才分段。每段至少约 256 KiB，512 并发需文件至少约 128 MiB；小文件自动减少实际连接数。服务器/代理/系统可能进一步限制或拒绝并发。
- 分段请求使用 If-Range；校验 206、精确起止/总大小、版本标识和 identity 编码，避免误拼版本已变化或忽略 Range 的响应。版本变化/不正确响应停止，不发布损坏成品。
- 429、5xx 或可恢复的分段连接中断最多重试两次（1/2 秒延迟），仅请求该段尚未写入的部分。不持久保存断点；单连接失败需重新开始。
- 同一目录的随机 `.twinfile-download-*.part` 临时文件，完成后检查长度、刷新磁盘并改名；不覆盖已有目标，下载途中出现同名文件也失败并保留原文件。磁盘已知空间不足时拒绝；写入失败会停止。文件大小/范围/版本检查不是来源真实性或密码学完整性验证，重要文件请再比对官方 SHA256。
- 探测传输超时 20 秒、下载传输超时 60 秒、整任务最长 24 小时；上限 1 TiB。正常失败/取消/关闭清理临时文件，强制结束进程或断电可能残留，可手动删除。

## 限制

不支持登录页、Cookie/自定义认证、内嵌账号密码链接、URL 片段、磁力/BT、跨重启断点、暂停、批量队列或自动解压/安装。带查询参数的临时签名直链可使用，但过期可能失败。遵守服务器限流和使用条款；高连接数不保证更快，遇限流请降低并发。跟随最多五次不降级重定向，不绕过 TLS 证书验证；不把输入链接和路径写入用户配置或遥测。默认无遥测不等于不联网：下载会直接访问用户填写的服务器。

自动回归仅访问本机模拟 HTTP 服务，包括实开 512 连接、内容 SHA256 对比、回退/异常/重试/取消与 UI 主题，不替代公网/CDN/代理/断电/超大文件性能测试。没有自动下载用户先前提供的固件。
