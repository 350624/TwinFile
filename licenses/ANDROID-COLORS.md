# Android Framework Colors

The offline system tonal palette and public color resource IDs in
`src/android.cpp` are adapted from the Android Open Source Project,
`platform/frameworks/base`, tag `android-12.0.0_r1`:

- `core/res/res/values/colors.xml`
- `core/res/res/values/public.xml`
- Source: <https://android.googlesource.com/platform/frameworks/base/+/refs/tags/android-12.0.0_r1/core/res/res/values/>

Copyright (C) 2006 The Android Open Source Project

Licensed under the Apache License, Version 2.0. See `Apache-2.0.txt`.
The original XML is represented as a bounded lookup table for numeric and
symbolic references. No Android runtime or wallpaper palette is loaded.
Actual device colors can differ due to wallpaper and manufacturer overlays.
